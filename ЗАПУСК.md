# BOTA — как запустить и открыть сайт

Инструкция для Windows. Нужен Node.js 24, на этом компьютере уже стоит 24.22. Интернет для запуска не нужен.

Сайт работает **на вашем компьютере**. Пока он запущен, его можно открыть в любом браузере на этом же компьютере. Окно, в котором он запущен, закрывать нельзя: закрыли окно — сайт остановился.

---

## Способ 1. Двойной щелчок (самый простой)

1. Откройте папку `C:\Users\User Home\Desktop\BOTA-Website-Assets`.
2. Дважды щёлкните файл **`start-bota.cmd`**.
   - Если Windows покажет синее окно «Система Windows защитила ваш компьютер», нажмите «Подробнее», затем «Выполнить в любом случае». Это наш собственный файл из папки проекта.
3. Откроется чёрное окно. Сначала идёт сборка (примерно 10–30 секунд), потом появится строка **`✓ Ready`**.
4. Браузер откроется сам на странице **http://127.0.0.1:3000**. Если не открылся, откройте эту ссылку вручную.
5. **Не закрывайте чёрное окно**, пока пользуетесь сайтом. Чтобы остановить сайт, закройте окно или нажмите в нём `Ctrl + C`.

## Способ 2. Через PowerShell (вручную)

### Шаг 1. Откройте PowerShell в папке проекта

Любой из вариантов:
- **Через проводник:** откройте папку проекта, кликните в адресную строку вверху, сотрите путь, напишите `powershell` и нажмите Enter.
- **Через «Пуск»:** нажмите `Win`, наберите `PowerShell`, нажмите Enter и перейдите в папку (кавычки обязательны):

```powershell
cd "C:\Users\User Home\Desktop\BOTA-Website-Assets"
```

Строка приглашения должна заканчиваться на `...\BOTA-Website-Assets>`.

> **Важно:** в PowerShell этого компьютера пишите **`npm.cmd`**, а не `npm`. Обычный `npm` выдаёт ошибку «выполнение сценариев отключено».

### Шаг 2. Только на новом компьютере: установите зависимости

На этом компьютере шаг не нужен, папка `node_modules` уже есть.

```powershell
npm.cmd ci --ignore-scripts --include=dev
```

### Шаг 3. Соберите сайт

Нужно в первый раз и после каждого обновления кода.

```powershell
npm.cmd run build
```

В конце не должно быть слова `Error`.

### Шаг 4. Запустите сайт

```powershell
npm.cmd start
```

Подождите строку `✓ Ready`. Окно не закрывайте.

### Шаг 5. Откройте сайт

В браузере (Chrome, Edge, Яндекс и т. д.) откройте адрес:

**http://127.0.0.1:3000**

Работает и адрес **http://localhost:3000**.

### Остановить сайт

В окне, где он запущен, нажмите `Ctrl + C`. Если появится вопрос «Завершить выполнение пакетного файла [Y(да)/N(нет)]?», введите `Y` и нажмите Enter. Можно просто закрыть окно.

## Что где менять

- Товары, цены (в тенге) и фото товаров — панель управления, вкладка «Товары».
- Тексты главной, фото главной и информационный блок внизу сайта — вкладка «Сайт: тексты и фото».
- Подробно — [АДМИНКА.md](АДМИНКА.md).

## Адреса сайта

| Что | Адрес |
|---|---|
| Главная | http://127.0.0.1:3000 |
| Каталог | http://127.0.0.1:3000/catalog |
| Корзина | http://127.0.0.1:3000/cart |
| Панель управления | http://127.0.0.1:3000/admin |

**Язык:** переключатель **RU / EN** находится справа в шапке, на телефоне — в «Меню». Выбор запоминается.

**Панель управления:** войдите с именем и паролем администратора. Как работать в панели, подробно описано в [АДМИНКА.md](АДМИНКА.md).

**Как посмотреть телефонную версию на компьютере:** откройте сайт в Chrome или Edge, нажмите `F12`, затем `Ctrl + Shift + M` и выберите вверху модель телефона. Открыть сайт с настоящего телефона в этой настройке нельзя: сайт доступен только на этом компьютере.

## После обновления кода

Остановите сайт (`Ctrl + C`), затем:

```powershell
npm.cmd run build
```

```powershell
npm.cmd start
```

Или просто снова запустите `start-bota.cmd`: он сам соберёт сайт заново. Если в браузере осталась старая версия, нажмите `Ctrl + F5`.

## Проверки (по желанию)

Перед ними остановите сайт: тестам нужны свободные порты 3107 и 3110.

```powershell
npm.cmd run typecheck
```

```powershell
npm.cmd test
```

## Если что-то не работает

| Что видите | Что делать |
|---|---|
| «Невозможно загрузить файл …\npm.ps1, так как выполнение сценариев отключено» | Пишите `npm.cmd` вместо `npm` или используйте `start-bota.cmd`. Разрешить навсегда можно командой `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, но это настройка безопасности Windows, решение за вами |
| `EADDRINUSE` или «порт 3000 занят» | Сайт уже запущен в другом окне. Найдите это окно и закройте его либо перезагрузите компьютер |
| Браузер пишет «Не удаётся получить доступ к сайту» | Сайт не запущен или ещё запускается. Проверьте, что окно открыто и в нём есть `✓ Ready` |
| `Could not find a production build` | Сначала выполните `npm.cmd run build` |
| Сайт выглядит по-старому | Остановите сайт, выполните сборку и запуск заново, в браузере нажмите `Ctrl + F5` |
| Ошибка при сборке | Пришлите последние строки из окна (без паролей) |
