# Временная демонстрация BOTA Group

Подготовлен бесплатный Render Web Service с запрашиваемым именем `botamedical`. Предполагаемый адрес — `https://botamedical.onrender.com`; это пока не опубликованный и не зарезервированный адрес. Доступность имени подтверждается только созданием сервиса. При занятом имени использовать `botamedical-demo` с коротким суффиксом.

## Подготовлено

`render.yaml` задаёт Node.js 24.22.0, `plan: free`, проверку `/healthz`, команды сборки/запуска, временный отдельный каталог данных и `BOTA_PUBLIC_DEMO=1`. Платных баз, дисков и других ресурсов нет.

Сборка: `npm ci --ignore-scripts --include=dev && npm run build`.
Запуск: `npm start`.
Внешний origin берётся из доверенной переменной Render `RENDER_EXTERNAL_URL`. Произвольный Host запроса не определяет разрешённый origin. Для своего домена позже понадобится явный `APP_ORIGIN`.

В Render сервер слушает `0.0.0.0:$PORT`. Обычный запуск на компьютере по-прежнему ограничен `127.0.0.1:3000`. Телеметрия Next.js отключена.

## Публичный деморежим

Работают главная, фотографии и увеличение, каталог, поиск, фильтры, сортировка, карточки и корзина в браузере. Не принимаются контакты и заказы, не доступны админка, её API, вход, загрузки и файлы из частного хранилища. Блокировки есть и в proxy, и в серверных проверках мутаций/авторизации. Страница оформления явно объясняет ограничение без формы для персональных данных.

При `BOTA_PUBLIC_DEMO` без значения `1` обычные локальные возможности остаются доступны. Рабочая `.local/` и её ключи/сессии/заказы не должны передаваться в хостинг. В публичной среде каталог создаётся из исходных демонстрационных записей в `/tmp/bota-public-demo`.

## Бесплатный тариф и отключение

Render Free может засыпать после 15 минут без посещений; первое открытие после сна будет медленнее. Локальный диск не постоянный: данные сбрасываются при перезапуске, redeploy и засыпании. Поэтому этот сервис предназначен для демонстрации витрины. Реальные заказы и редактирование каталога нужно размещать отдельно с постоянным хранилищем.

При публикации выбрать именно Free; не подключать оплату, платные ресурсы или покупку домена. Если сервис потребует карту, upgrade или списание — остановить этот шаг. Работа ограничена бесплатными квотами аккаунта, их расход необходимо видеть в Render.

После демонстрации владелец может Suspend сервис в Render. Удаление сервиса выполняется отдельным действием владельца. Автоматическая дата отключения пока не назначена.

## Текущее состояние

Конфигурация и код подготовлены. Сборка и 13 тестов прошли, включая HTTPS-origin, ошибочный Host, недоступность всех частных маршрутов и сохранение обычного локального режима. Аудит runtime-зависимостей не сообщил известных уязвимостей.

Плагин Render установлен, но доступ к аккаунту Render пока не подключён и инструменты управления сервисами недоступны. Сайт ещё не создан, имя не зарезервировано, удалённый URL не проверен. Для завершения требуется подключить аккаунт Render в Codex; затем подготовить закрытый репозиторий исходников, создать Free Web Service, дождаться успешной сборки и проверить фактический HTTPS-адрес. Секреты `.local/`, `.env*`, `node_modules/`, `.next/` и снимки из `test-results/` не отправлять.
