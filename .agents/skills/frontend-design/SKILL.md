# Frontend design for BOTA Group

This is a BOTA adaptation, not the unmodified Anthropic skill. Read [project adaptations](../../../docs/agent-guides/BOTA-ADAPTATIONS.md), then the [pinned design reference](../../../docs/agent-guides/upstream/anthropic-frontend-design/SKILL.source.md) for a design task.

Ground choices in the approved BOTA brief, real medical apparel, materials, audience, and supplied assets. Propose a compact palette, type hierarchy, composition, and one purposeful focal interaction before implementation when that work is authorized. Treat an existing approved design as a constraint.

The upstream story about a client rejecting past proposals is hypothetical. Do not present it as BOTA history. Stylistic preferences and anti-pattern lists are prompts for judgment, not bans on a brand-approved treatment. Do not import Anthropic or Vercel colors, fonts, layouts, or branding.

For Russian interfaces use natural Russian labels, appropriate punctuation, fonts with verified Cyrillic coverage, and an explicit locale/currency. Preserve BOTA's approved spelling. Use real product content; do not invent fabric properties, certifications, stock, prices, or photographic details.

Product motion and zoom need touch and keyboard alternatives, clear focus, and reduced-motion behavior. Match the interaction to available source imagery; a single photograph does not establish a truthful 360-degree view.

When a running page exists and browser checks are authorized, use the environment's permitted browser interface for visual critique. Report what was actually checked; do not install or launch an alternative browser tool just because a reference mentions screenshots.
