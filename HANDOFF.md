## 2. Архитектура

## 5. Zoom: фактическое состояние и открытые вопросы

20 октября тест математики zoom прошёл. Production-сцена загрузилась, шесть нажатий «+» дали zoom≈4.8268 и distance≈.4187; «−» — zoom≈3.7129 и distance≈.5272; «Сбросить» вернул zoom=1. Колесо вверх над моделью после сброса увеличило zoom до≈1.4333. Изменение масштаба видно на живом canvas, материал сохранился; console warn/error в этих сценариях пусто. При нажатиях viewport немного прокрутился к управлению, progress стал≈.08559: численные расстояния не относятся строго к progress=0.

**Полное устранение жалобы на ограниченный zoom не подтверждено.** Текущий предел дистанции: `max(min(3.4, pose.distance / zoom), front + .09, .12)`, где front — max.z общего AABB повёрнутого халата. После достижения этого предела zoom в controls может продолжать расти без видимого приближения. На боковых ракурсах объёмный bounds способен ограничивать приближение раньше локальной поверхности ткани. Это объяснение по коду, не установленная причина исходной жалобы.

Не проверены pinch на физическом телефоне, все пять глав × ракурсы × крайние zoom, Ctrl+wheel, клавиатурный обход, reduced motion, возврат после фото/каталога и устойчивость WebGL на слабом GPU. Reset возвращает angle/zoom, но не выключает inspecting; оценить ожидаемое поведение при продолжении. Проверки математики не заменяют событийные/визуальные тесты.

Из корня проекта на новой машине после разрешения владельца на восстановление зависимостей:

```powershell
npm ci --ignore-scripts --include=dev
npm run build
npm run typecheck

```

Администратора владелец создаёт интерактивно через `npm run admin:create`; стандартного пароля нет.

Переменные (имена, без секретных значений): `BOTA_DATA_DIR` — частное хранилище; `APP_ORIGIN` — доверенный origin; `PORT`, `BOTA_BIND_HOST` — bind; `BOTA_PUBLIC_DEMO=1` — закрыть приём частных данных/админку; `RENDER`, `RENDER_EXTERNAL_URL` — существующая конфигурация хостинга. Изменение PORT требует согласовать APP_ORIGIN. Для обычного localhost ничего задавать не нужно. Next telemetry выключается wrapper-скриптом.

Необязательная регенерация производных (перезаписывает их, для запуска не нужна): `npm run assets`; `node scripts/prepare-coat.mjs`. Генерация сцены требует Blender с bpy/numpy и совместимого API Principled; точная установленная версия Blender этим аудитом не подтверждена. Последовательность уже имеющихся скриптов: Blender `--background --factory-startup --python models/bota-coat-20261016/fabric_v4.py`, затем аналогично `optimize_web.py -- fabric-v4`, `render_v4.py`, затем prepare-coat. **Сейчас эти команды не выполнять:** сначала отдельная резервная копия и задача на материал; экспорт может различаться между версиями Blender.
