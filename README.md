# BOTA Group — локальный MVP

Рабочая демонстрационная витрина медицинской одежды. Интерфейс на русском. Цены обозначены в условных единицах, реальные характеристики и наличие не выдуманы. Платежей, отправки продавцу и доставки нет.

## Запуск

Требуется Node.js 24. В PowerShell из папки проекта:

```powershell
npm run dev
```

Адрес: **http://127.0.0.1:3000**. Используйте именно этот адрес: проверка Host/Origin намеренно не допускает произвольные имена хоста.

Проверка production-сборки и её запуск вместо dev-сервера:

```powershell
npm run build
npm start
```

Не запускайте два сервера на одном порту. При изменении кода production-сервер нужно остановить, пересобрать и запустить снова. Разработческий сервер обновляет приложение автоматически.

Зависимости уже установлены. Для восстановления из lockfile: `npm ci --ignore-scripts`. Скрипты сторонних установщиков отключены; для текущих Windows-пакетов Next.js и Sharp этого достаточно.

## Администратор

```powershell
npm run admin:create
```

Команда работает в интерактивном терминале. Введите имя из 3–64 латинских букв/цифр, `_` или `-` и пароль длиной 14–128 символов. Пароль при вводе скрыт и сохраняется только как scrypt-хеш. Стандартных учётных данных, публичной регистрации и обходного входа нет.

Затем откройте **http://127.0.0.1:3000/admin**. Если страница уже открыта, обновите её. Повторный запуск команды с существующим именем предлагает сбросить пароль после ввода `RESET` и отзывает его сессии.

В панели реализованы создание, редактирование, скрытие и удаление товаров, цены, категории, размеры/цвета, загрузка до восьми фотографий, просмотр тестовых заказов, изменение их статуса и удаление. Пустые размеры/цвета означают, что данные не подтверждены. Фото загружаются как двоичные данные, проверяются и перекодируются в WebP; SVG/HTML не принимаются. Удаление фото из карточки не удаляет файл с диска.

## Что работает

- Главная, каталог, поиск, категории и сортировка с параметрами в URL.
- Карточка товара, увеличение фото ×2, выбор вариантов при наличии данных.
- Корзина: добавление, удаление, целое количество, пересчёт и сохранение между посещениями.
- Форма заказа: клиентская и серверная валидация, проверка актуальной цены и вариантов, защита от повторного сохранения одного запроса.
- Постоянное хранение каталога, файлов, заказов и сессий. Контакты в заказе зашифрованы AES-256-GCM.
- Серверная авторизация каждого административного API, HttpOnly/SameSite cookie, отзыв сессии при выходе, лимиты входа и запросов, Origin + обязательный заголовок для изменений, nonce CSP.

## Стек и структура

Next.js 16.4.1 (App Router), React 19.3.1, TypeScript 7.0.2, CSS, Zod 4.6.7, Sharp 0.35.5, SQLite через `node:sqlite` Node.js 24. Точные версии зафиксированы в `package-lock.json`. Прочитана документация установленного Next.js из `node_modules/next/dist/docs`.

- `app/` — страницы, HTTP-маршруты, стили.
- `components/` — повторно используемые элементы и клиентские сценарии.
- `lib/` — типы, валидация, база, шифрование, сессии, проверки запросов.
- `scripts/` — запуск, подготовка копий изображений, создание администратора.
- `tests/` — интеграционные тесты с отдельной временной базой.
- `public/images/` — оптимизированные копии пяти исходных изображений.
- `.local/` — данные работающего магазина; исключены из Git и трассировки сборки.
- `docs/agent-guides/`, `.agents/skills/`, `AGENTS.md` — ранее подготовленные инструкции, сохранённые без изменений.

Оригинальные `catalog/`, `hero-coat/`, `logo.jpg/` сохранены. `npm run assets` заново создаёт производные WebP-копии. Назначения файлов записаны в `docs/assets-manifest.json`. В проекте пока нет Git-репозитория; никакие настройки GitHub не менялись.

## Данные и ограничения локального хранилища

`bota.sqlite`, WAL/SHM-файлы, ключ `order-key` и папка `uploads` находятся внутри `.local/`. Их нельзя публиковать или добавлять в репозиторий. Для согласованной резервной копии остановите приложение и сохраните всю папку `.local` в защищённом месте. Потеря `order-key` делает сохранённые заказы нечитаемыми; приложение не заменяет отсутствующий ключ при существующих заказах.

Шифрование защищает содержимое отдельного файла базы, но не от пользователя/процесса, имеющего доступ одновременно к базе и ключу. На Windows права наследуются от папки; режимы POSIX `0600/0700` не заменяют Windows ACL. Перед реальными данными нужен отдельный сервисный пользователь, ограниченные права на хранилище и защищённое хранение/резервирование ключа. Сейчас используйте вымышленные контакты.

Данные рассчитаны на один локальный Node-сервер и постоянный диск. Serverless с временным диском не подходит. Для будущего небольшого VPS SQLite допустим после настройки резервирования; для нескольких экземпляров следует выделить БД/сессии/лимиты и файловое хранилище. Загрузка файлов ограничена 6 МБ, 24 Мп, 6000 px и 30 запросами в минуту; общий размер диска пока контролируется владельцем. Лимиты запросов общие для локального MVP и не предназначены для публичного магазина с большой нагрузкой.

## Проверки

```powershell
npm run typecheck
npm run build
npm test
```

Тестам нужна актуальная `.next`-сборка и свободный порт 3107. Они используют случайный пароль в памяти, отдельную временную SQLite-базу и не меняют рабочий каталог. `npm test` включает 10 предметных проверок (11 записей с родительским тестом).

Фактический результат и ограничения браузерной проверки: `docs/MVP-STATUS.md`. Скриншоты лежат в `test-results/` и не предназначены для Git.

## До коммерческого запуска

Подтвердить ассортимент, валюту и цены, характеристики, размеры, наличие, права на фотографии, контакты и условия продаж. Затем настроить хостинг с HTTPS, постоянный диск, резервное копирование и восстановление, права доступа и хранение ключей, мониторинг, обработку настоящих заказов/уведомлений, доставку и при необходимости платежи. Подготовить документы о данных, оплате и возвратах для выбранной юрисдикции. Повторно проверить зависимости, авторизацию, конкурентные заказы и браузерную доступность; настроить индексацию, которая сейчас отключена.

Это локальный MVP, не готовый к публичному приёму оплачиваемых заказов. Подключения, оплаты услуг и публикация не выполнялись.
